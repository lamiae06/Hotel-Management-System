# 🏨 Hotel Management System

A C++ console application for managing hotel operations, including rooms, clients, reservations, and billing. The project demonstrates object-oriented programming, memory management, and relationships between classes.

## ✨ Features

- **Room Management** — Add rooms, check availability, and manage occupancy.
- **Client Management** — Register clients and prevent duplicate registrations.
- **Reservation Management** — Create and cancel reservations with automatic room availability updates.
- **Billing System** — Calculate reservation costs based on the number of nights and room prices.
- **Revenue Tracking** — Calculate total revenue from active reservations.
- **Memory Management** — Manage dynamically allocated objects and arrays.

## 🛠️ Technologies

- **Language:** C++
- **Standard:** C++17
- **Programming Paradigm:** Object-Oriented Programming (OOP)
- **Code Editor:** Visual Studio Code

## 🧠 Concepts Demonstrated

- Classes, objects, constructors, and destructors
- Encapsulation and static members
- Composition, aggregation, association, and dependency
- Pointers and dynamic memory allocation (`new` / `delete`)
- Object ownership and lifetime management
- Constant members and deleted copy operations
- Modular programming with separate header (`.h`) and source (`.cpp`) files

## 🎯 Project Goal

The goal of this project is to build a structured hotel management application while developing a deeper understanding of C++ object-oriented design, relationships between objects, and resource management.
